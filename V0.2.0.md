# Trove v0.2.0 — Search Engine

## Delivered

- Provider adapter contract (`TravelProvider`)
- Two independent mock providers
- Parallel provider aggregation
- Normalized tour domain model
- Offer deduplication
- Trove recommendation ranking
- Search filters: text, destination, departure, price, rating, duration
- Sorting: recommended, price, rating, duration
- Pagination
- `GET /api/providers`
- `GET /api/tours`
- `GET /api/tours/:id`
- Frontend `useTours` connected to the API
- Frontend fallback to demo data while API is offline

## Next

v0.3 should introduce the first real provider research/integration layer, booking boundaries, caching and a proper provider availability/price contract.
