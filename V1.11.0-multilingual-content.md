# Trove v1.11.0 — Multilingual + Homepage Content

## Multilingual
Added application-level locale foundation with RU / EN / ES / KK.
- persistent locale selector in header and footer;
- reactive locale state via `useI18n`;
- homepage content requests locale-specific public content;
- promotion translations stored as JSONB per locale;
- `kk` is used for Kazakh while the visible selector uses `KZ`.

## Homepage CMS
Added `promotions` and `homepage_blocks`.

Promotion fields:
- slug
- status
- image
- badge
- start/end dates
- priority
- RU/EN/ES/KK copy and CTA

Homepage block types:
- hero
- text
- image
- promotion
- tours
- guides
- destinations

Admin API:
- `GET/POST /api/admin/promotions`
- `GET/DELETE /api/admin/promotions/:id`
- `GET/POST /api/admin/homepage-blocks`
- `GET/DELETE /api/admin/homepage-blocks/:id`
- `GET /api/content/home?locale=ru|en|es|kk`

Migration: `010_homepage_content.sql`.
