# Trove v1.0.8 — Full Local Booking Journey

## Goal
Complete one booking flow locally without external credentials.

```text
Search
  ↓
Provider price check
  ↓
Provider preview
  ↓
Trove booking preview
  ↓
Payment Intent
  ↓
Mock hosted checkout
  ↓
Signed payment webhook
  ↓
Payment = succeeded
  ↓
Provider booking
  ↓
CONFIRMED
  ↓
My Trips
```

## Backend
- deterministic `MockBookingProvider` preview prices now match mock-a offers;
- full journey integration script at `backend/src/integration/full-booking-journey.ts`;
- `pnpm test:journey` runs registration → preview → payment → provider booking → confirmation;
- `pnpm test:all` runs provider contract harness and full journey;
- lifecycle assertions verify final booking and payment states.

## Frontend
- booking page no longer auto-confirms payment immediately;
- new `/payment/mock/:id` local checkout screen;
- checkout visualizes payment/provider/confirmation stages;
- signed mock webhook remains behind the backend mock provider;
- successful flow redirects to My Trips.

## Production boundary
The mock checkout is explicitly a development/test flow. A real deployment must replace it with a hosted/tokenized PSP checkout and verified provider webhooks. Trove must not receive or store raw card data.

## Verification
The artifact was not dependency-installed in this environment, so `pnpm test`, `pnpm type-check`, and `pnpm build` are not claimed as executed successfully.
