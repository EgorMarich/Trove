# Trove v1.2.3 — Real Beta QA

## What changed
- Hardened My Trips booking detail with an explicit loading state instead of showing “not found” during the first request.
- Added a booking lifecycle timeline for created → payment → provider → confirmed states and terminal failure/cancellation states.
- Added a safe payment retry action for bookings stuck in `payment_failed`.
- Added clear cancellation handling when a provider-backed booking can no longer be cancelled locally.
- Added My Trips and Support navigation to the payment return page so users are never left on a dead-end recovery screen.
- Extended the local full-booking journey integration with a cancellation-path check and the current consent contract.
- Bumped project/backend versions to 1.2.3.

## Verification
- Static source checks are included with the release package.
- Full TypeScript/build/test execution still requires dependencies (`pnpm install`) and reachable PostgreSQL/Redis where the selected tests need them.
