# Trove v1.6.0 — UI refinement

This release keeps the v1.2.9 backend/business foundation and performs a deeper product UI pass.

## Design changes
- Removed the legacy `trove_v129_work` project-root naming from the distributable project.
- Unified typography: Inter for interface/body, Manrope for display/headings.
- Reduced oversized vertical whitespace and made sections visually denser.
- Added explicit surface boundaries, borders and section backgrounds so content does not visually merge.
- Reworked the home hero around a single primary search task.
- Improved country autocomplete, guest picker and search loading state.
- Reworked tour cards and results page hierarchy.
- Kept loading, empty and error states.
- Preserved existing API/composable/business functionality.

## Verification
- Archive structure checked.
- No distributable path contains `trove_v129_work`.
- Full Nuxt build was not executed in this environment because dependencies are not installed.
