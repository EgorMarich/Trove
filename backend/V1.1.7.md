# Trove v1.1.7 — Real Hosted Payment Provider

## Added
- YooKassa hosted redirect payment adapter.
- Server-side Basic Auth to YooKassa API.
- Idempotent payment creation.
- Dynamic payment return URL per payment intent.
- Persistent checkout URL on payment intents.
- YooKassa webhook endpoint with authoritative payment re-fetch.
- Payment amount/currency verification before marking an intent paid.
- Frontend payment return page that reconciles before booking confirmation.
- Production configuration validation for YooKassa credentials.

## Important
Trove never receives or stores raw card data. The customer is redirected to YooKassa hosted checkout. The redirect back to Trove is not treated as proof of payment; Trove reconciles the payment through the provider API.

Official API references: https://yookassa.ru/developers/payment-acceptance/getting-started/quick-start and https://yookassa.ru/developers/using-api/webhooks
