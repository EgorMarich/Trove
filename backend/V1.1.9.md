# Trove v1.1.9 — Production Operations

## Delivered

- structured JSON logging for the API;
- lightweight operational metrics with protected `/api/ops/metrics`;
- `/api/ready` readiness endpoint with PostgreSQL + Redis checks;
- reconciliation worker for payment intents and provider orders;
- reconciliation indexes in PostgreSQL;
- graceful worker shutdown;
- PostgreSQL backup and restore scripts;
- production deployment documentation for monitoring, backups and restore drills.

## Reconciliation rules

Payment intents in `processing`/`unknown` states are reconciled against the configured payment provider.
Provider orders in `unknown`/`pending` states are reconciled only when a provider order identifier exists. An unknown provider create without an authoritative remote identifier is not blindly retried; it remains a manual-review case.

## Important production limitation

The worker is a foundation, not a complete managed operations platform. Before real launch, configure external monitoring/alerting, durable off-host backups, retention policies, and a tested restore drill.
