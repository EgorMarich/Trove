# Trove v1.2.0 — Launch Candidate foundation

## Added
- production-safe anonymous product analytics endpoint with strict event allowlist and rate limiting;
- frontend analytics composable for core funnel events;
- global SEO metadata and configurable public site URL;
- `robots.txt` and `sitemap.xml` server routes;
- privacy, terms and support pages;
- footer navigation to support/legal pages;
- search funnel now carries date and traveler count into the results query;
- production frontend no longer silently replaces failed API search with demo data;
- explicit search error state with retry.

## Important
- Legal pages are launch templates and require final legal text/requisites before public commercial launch.
- Analytics are structured logs, not a replacement for a full analytics warehouse/product analytics platform.
- No real payment/provider credentials are included.
- Full build/typecheck/tests still require installed dependencies; the source archive does not contain `node_modules`.
