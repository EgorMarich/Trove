# Trove v1.2.4 — Production Smoke & Deployment

## Goal

Move the project from beta QA to a repeatable production deployment path without pretending that real third-party credentials or live provider access are already configured.

## Included

### Production database migrations
- Added migration `007_production_operations.sql`.
- Production Compose now has a dedicated one-shot `migrate` service.
- Migrations are recorded in `schema_migrations` and are applied only once.
- Backend starts only after the migration job completes successfully.

### Payment configuration
- Production Compose now passes YooKassa configuration to the backend.
- Production preflight requires YooKassa credentials when `PAYMENT_PROVIDER=yookassa`.
- HTTPS is required for the public origin and payment return URL.
- Mock payments are rejected by production preflight.

### Booking.com configuration
- Production Compose exposes the provider configuration used by the adapter.
- Native booking remains disabled by default.
- If native booking is enabled, production preflight requires the Booking.com API key and affiliate ID.

### Deployment checks
Added:
- `deploy/preflight.sh`
- `deploy/compose-preflight.sh`
- `deploy/smoke.sh`
- `deploy/scripts/verify-backup.sh`

Smoke checks cover:
- frontend
- `/api/ready`
- `/api/health`
- `/api/providers`
- `/api/providers/health`
- `robots.txt`
- `sitemap.xml`

### Backup operations
- Existing PostgreSQL backup/restore scripts retained.
- Added backup archive verification with `pg_restore --list`.

### Documentation
- Reworked `deploy/README.md` into a concrete deployment runbook.
- Documented startup order, migration behavior, smoke testing, backups, and real-provider rollout.

## Version

- root: `1.2.4`
- backend: `1.2.4`
- frontend: `1.2.4`

## Verification limitation

The working environment does not have Docker or access to the npm registry, so a real container build, Compose startup, TypeScript compilation, and live smoke test could not be executed here. Static source/configuration validation was performed instead.
