# Trove v2.6.0 — Design + Marketing OS

This release combines the polished Trove v1.11 design/product build with the v2.5 marketing/content engine.

## Product/UI base retained from v1.11
- Current Trove homepage and visual design system.
- RU/EN/ES/KZ locale foundation.
- Homepage CMS with promotions and managed blocks.
- Admin back office: users, bookings, tours, providers, guides, audit.
- Tour overrides and provider health.

## Marketing OS added from v2.5
- Marketing event collection and persistent event storage.
- Customer 360 / intent scoring.
- Personalized tour ranking and impression tracking.
- Audiences and campaign drafts.
- Event-driven automations and execution log.
- Marketing overview/funnel and opportunity signals.
- Rules-based Marketing AI strategist.
- Demand-driven content engine for guides/SEO/email/Telegram/onsite drafts.
- Marketing admin workspace under the existing authenticated Back Office.

## Integration details
- Existing v1.11 admin authentication remains the source of truth.
- Marketing admin pages use the same Admin layout and session/CSRF-aware API client.
- Marketing endpoints accept the existing admin session; `MARKETING_ADMIN_TOKEN` remains available for server-to-server access.
- Existing homepage CMS remains separate from the marketing content engine. Marketing content drafts are not auto-published.
- Marketing automation external delivery remains queue-only until an approved communications connector is connected.

## Database migrations
Existing v1.11 migrations remain untouched. Marketing migrations are appended as:
- 011_marketing_os.sql
- 012_marketing_engine.sql
- 013_marketing_automation_engine.sql
- 014_customer_360.sql
- 015_personalization_engine.sql
- 016_content_engine.sql
