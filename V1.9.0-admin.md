# Trove v1.9.0 — Admin / Back Office

## Что добавлено

- `/admin/login` — вход администратора через существующую session-auth систему.
- RBAC: `user`, `admin`, `manager`, `editor`.
- `/admin` — dashboard со статистикой пользователей, бронирований, оборота, активности и популярных направлений.
- `/admin/users` — поиск и фильтрация пользователей.
- `/admin/users/:id` — история бронирований и активности пользователя.
- `/admin/bookings` — операционная таблица бронирований.
- `/admin/tours` — фильтрация реальных предложений через существующий search/provider слой.
- `/admin/guides` — CMS для создания, редактирования, публикации и удаления статей.
- Публичные `/api/guides` endpoints для опубликованных материалов.
- PostgreSQL migration `008_admin_cms.sql`: роли пользователей, статьи, события активности.
- Audit events для операций CMS.
- Analytics events теперь сохраняют user activity в PostgreSQL, если пользователь авторизован.
- Исправлена цепочка Nuxt layouts: `app.vue` теперь использует `<NuxtLayout>`, поэтому public `default.vue` реально рендерит Header/Footer.

## Создание первого администратора

После миграций: `DATABASE_URL=... ADMIN_EMAIL=... ADMIN_PASSWORD=... pnpm --dir backend admin:create`

Пароль должен содержать минимум 8 символов. Скрипт создаёт или повышает указанного пользователя до `admin`.

## Миграции

```bash
pnpm --dir backend db:migrate
```

## Запуск

```bash
pnpm --dir backend dev
pnpm --dir frontend dev
```

Admin UI: `http://localhost:3000/admin`
API: `http://localhost:3001/api/admin`

## Важно

Туры в админке не копируются в отдельную таблицу: `/admin/tours` использует существующий provider/search слой, поэтому оператор видит те же предложения, которые получает клиент.
