# Trove v1.1.6 — Production Deployment Foundation

## Goal

Move Trove from infrastructure-only development toward a repeatable production-shaped deployment without pretending that a real payment provider is configured yet.

## Added

- Node HTTP server using `@hono/node-server`.
- Graceful shutdown for PostgreSQL and Redis.
- Backend and frontend production Dockerfiles.
- Production Docker Compose stack.
- Caddy reverse proxy with automatic HTTPS.
- Same-origin `/api` routing in production.
- Production environment example.
- Production validator rejects `mock-payment`.
- Health endpoint reports payment provider readiness without secrets.

## Production topology

```text
Internet
   |
 Caddy :443
   |------ /api/* ------> Hono API
   |                         |
   |                         +--> PostgreSQL
   |                         +--> Redis
   |
   +-----------------------> Nuxt
```

## Still required before real users

- real payment provider adapter and credentials;
- Booking.com production/sandbox access and booking contract verification;
- production database backups + restore drill;
- monitoring/error tracking/alerts;
- real email/SMS/transactional communication provider;
- legal documents and support process;
- production smoke tests and load/rate-limit testing.
