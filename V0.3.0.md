# Trove v0.3.0 — Provider Integration Foundation

## What changed

- Added `ProviderCapabilities` so Trove knows whether a supplier supports search, price validation, native booking or redirect.
- Extended the normalized offer with `sourceUrl`, `bookingUrl` and `priceUpdatedAt`.
- Added `checkPrice()` to the provider contract and `GET /api/tours/:id/price`.
- Added `GET /api/tours/:id/redirect?provider=...` as the explicit booking boundary for redirect-based providers.
- Added a `BookingProvider` contract for future native checkout without coupling the search engine to a supplier.
- Demo providers now expose redirect and price-check capabilities without pretending to support real bookings.
- Added provider integration research notes and partner-gated integration guidance.

## API boundary

```text
GET /api/tours
        ↓
Normalized offer
        ↓
GET /api/tours/:id/price?provider=...
        ↓
price/availability validation
        ↓
GET /api/tours/:id/redirect?provider=...
        ↓
external booking / affiliate flow
```

Later, providers that support an integrated checkout can implement `BookingProvider.createBooking()` without changing the search UI contract.
