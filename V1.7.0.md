# Trove v1.7.0 — Frontend UI refinement

## Focus
A substantial frontend visual pass focused on product clarity, typography, search usability, stronger section separation and image resilience.

## Changes
- Reworked global typography: Inter for interface/body, Manrope for display hierarchy.
- Added explicit global link styling to prevent browser-default purple links.
- Increased body, heading and control sizes and improved contrast.
- Rebuilt homepage composition with tighter vertical rhythm and clearer surfaces.
- Rebuilt the main travel search: clearer fields, destination autocomplete with flags/cities, guest picker, loading state and popular destinations.
- Added stronger card boundaries, borders and surface hierarchy.
- Reworked tour cards and search results layout.
- Reworked Hot and Trove Guide pages to use the same visual system.
- Added image error fallbacks to prevent broken image icons in key redesigned areas.
- Kept existing business/API/auth/booking functionality intact.

## Validation
- Archive structure checked.
- No full Nuxt build was claimed because dependencies are not installed in the working environment and npm dependency installation timed out.
