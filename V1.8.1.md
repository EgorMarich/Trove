# Trove v1.8.1 — Release journey audit

## Goal
Final visual/UX consistency pass after the v1.8.0 product polish. The focus is the full customer journey rather than adding new features.

## Changes
- Fixed home-page guide cards so each card opens its actual article instead of the generic guide index.
- Fixed the guide catalogue/article mismatch by adding a real Dubai article route (`/guides/dubai-without-rush`).
- Reworked payment mock and payment-return screens to use the same Trove design tokens, typography, surfaces, buttons, errors and responsive behavior as the rest of the product.
- Reworked support and legal document pages to remove the remaining legacy visual system and browser-default link treatment.
- Removed legacy page-level color imports from the booking detail page.
- Bumped project version to 1.8.1.

## Audit
- Verified all `.vue` files have balanced top-level template/script/style tags.
- Verified the Nuxt page route set includes the new guide route and the existing payment/account flows.
- Checked static internal links for known route targets; dynamic parameterized routes are intentionally represented by Nuxt dynamic pages.

## Verification limitation
A full Nuxt production build was not executed in this isolated environment because project dependencies are not installed and network access is unavailable.
