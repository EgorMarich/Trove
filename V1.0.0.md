# Trove v1.0.0 — Real Provider Ecosystem Foundation

## Delivered

- Added a real Booking.com Demand API v3.2 provider adapter.
- Provider uses Bearer API key + X-Affiliate-Id headers.
- Sandbox is the default API base URL.
- Added accommodation search normalization into Trove's common offer model.
- Added live availability / price re-check through `/accommodations/availability`.
- Added provider-side redirect fallback using the returned Booking.com URL.
- Provider remains disabled until credentials are configured.
- Added configurable Booking.com city ID mapping through `BOOKING_CITY_MAP_JSON`.
- Added provider status `enabled` to `/api/providers`.
- Added accommodation-aware UI on the offer detail page: hotel offers no longer pretend to contain a flight.
- Existing mock providers remain active, so Trove continues working without external credentials.

## Environment

Copy `backend/.env.example` to the backend environment and provide:

- `BOOKING_API_KEY`
- `BOOKING_AFFILIATE_ID`
- `BOOKING_CITY_MAP_JSON`
- optionally `BOOKING_DEFAULT_CITY_ID`
- optionally `BOOKING_CURRENCY` and `BOOKING_BOOKER_COUNTRY`

## Current provider flow

```text
Trove Search
    ↓
Mock Providers + Booking.com (when credentials exist)
    ↓
Normalization
    ↓
Deduplication / Recommendation
    ↓
Trove Offer
    ↓
Price Check
    ↓
Booking.com redirect fallback
```

## Important boundary

The current Booking.com adapter intentionally uses **Search + Availability + Redirect**. It does not claim native Booking.com order creation yet.

Booking.com's current Demand API supports an integrated Search, look and book flow for eligible accommodation partners, using availability, `/orders/preview`, and `/orders/create`. Native order creation will be the next provider milestone after the search/availability adapter is validated.

## Provider requirements

Booking.com states that Demand API access requires a Managed Affiliate Partner setup, Partner Centre access, API key and affiliate ID. The sandbox uses the same credentials and is intended for validating accommodation search, availability and booking flows.
