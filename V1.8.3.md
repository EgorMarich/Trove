# Trove v1.8.3 — Search & discovery UX

## Added
- Custom accessible date/range picker for the main search and filters.
- Single-date and date-range modes, presets, nights count, past-date disabling, keyboard navigation and mobile fullscreen sheet.
- Guide recommendations carousel using native CSS scroll-snap; no extra dependency.
- Expanded tour filters with URL query persistence.
- Functional dual-handle price slider with manual inputs and 1,000 ₽ step.
- Custom accessible checkbox component with checked, focus, disabled and indeterminate states.
- Header authentication UI with guest actions and authenticated profile menu/logout.
- Multi-level responsive footer with newsletter form, legal links, locale/currency controls and mobile accordions.

## Fixed
- Search date input was a native browser date field and did not support ranges/presets.
- Search results price range was only decorative and had no state or filtering connection.
- Filter checkboxes were native/default controls with inconsistent visual state.
- Authentication actions were too easy to miss in the header.
- Guides recommendations had no responsive slider behavior.

## Notes
- The guides carousel intentionally does not use infinite looping: finite content is easier to navigate with keyboard/screen readers and avoids duplicated focus targets.
- No new runtime dependency was added.
- Full Nuxt build was not run in this environment because dependencies are not installed and package-manager downloads are unavailable.
