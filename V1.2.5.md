# Trove v1.2.5 — Real Beta Environment

## Goal
Provide a reproducible local beta environment that exercises the real HTTP application boundary with PostgreSQL, Redis, the frontend, mock payment and the mock booking provider.

## Added
- `deploy/docker-compose.beta.yml` — isolated beta stack.
- `deploy/.env.beta.example` — safe local beta configuration template.
- `deploy/beta-up.sh` / `beta-down.sh` — lifecycle commands.
- `deploy/beta-e2e.sh` + `beta-e2e.mjs` — HTTP end-to-end smoke journey.
- root `beta:up`, `beta:down`, `beta:e2e` scripts.
- version bumped to 1.2.5.

## E2E journey
`health → ready → search → register → verify → login → preview → payment → provider booking → My Trips`

The beta stack deliberately uses `PAYMENT_PROVIDER=mock-payment`. This is a test environment and must never be reused as production.

## Run
```bash
cp deploy/.env.beta.example deploy/.env.beta
pnpm beta:up
pnpm beta:e2e
pnpm beta:down
```

Requires Docker and pnpm/corepack.

## Production boundary
Production continues to reject `mock-payment`. Real YooKassa and Booking.com sandbox credentials remain a separate rollout step.
