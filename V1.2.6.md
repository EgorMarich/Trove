# Trove v1.2.6 — Beta Quality Gate

## Goal
Turn the beta environment into a repeatable quality gate for the highest-risk real-user flows before connecting real PSP/provider credentials.

## Added
- `deploy/beta-quality-gate.mjs` — HTTP-level beta QA suite.
- `deploy/beta-quality-gate.sh` — shell entrypoint.
- root `pnpm beta:qa` command.

## Covered scenarios
1. Health/readiness.
2. Search and demo offer availability.
3. Register → verify → login.
4. CSRF rejection for authenticated mutations.
5. Booking preview idempotency.
6. Simulated payment failure.
7. Duplicate payment webhook idempotency.
8. Fresh payment intent after a failed payment.
9. Successful payment retry.
10. Provider booking confirmation.
11. Provider cancellation boundary for confirmed bookings.
12. Booking recovery on an authoritative confirmed order.
13. Cross-user booking/payment isolation.
14. Idempotency-key input validation.
15. Security headers.

## Run

```bash
pnpm beta:up
pnpm beta:qa
pnpm beta:down
```

Or:

```bash
TROVE_BETA_API_URL=http://localhost:3001 ./deploy/beta-quality-gate.sh
```

## Verification limitation
This release was validated with static/source checks and archive integrity in the current environment. Full Docker E2E and TypeScript compilation still require a runtime with Docker/Node dependencies installed.
