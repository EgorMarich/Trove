# Trove v1.8.0 — Product UI refinement

## Goal
Bring the frontend closer to a polished travel aggregator product: stronger hierarchy, tighter layout, clearer surfaces, consistent typography and reliable image fallbacks.

## Frontend
- Rebuilt the home hero and search experience.
- Added a stronger, compact visual hierarchy across Home, Tours and Tour Detail.
- Standardized typography: Inter for UI/body, Manrope for display typography.
- Added explicit global font application and Google Fonts loading in Nuxt head.
- Removed browser-default purple link presentation through global and component link styles.
- Added local fallback artwork at `public/images/trove-landscape.svg` for failed remote images.
- Refined guest picker with adults/children controls and clearer hierarchy.
- Refined tour cards, filters, search summary, booking form, auth pages, account and favorites.
- Added loading skeleton for tour detail.
- Kept existing business logic, routes, auth, booking and provider integrations intact.

## Project structure
The release archive root is `Trove/`; no `trove_v129_work` branch/work-directory wrapper is used.

## Verification
- Archive structure checked.
- Source-level consistency checks performed.
- Full Nuxt build was not executed in the isolated environment because project dependencies are not installed.
