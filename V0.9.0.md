# Trove v0.9.0 — CRM & Communications

## Delivered
- channel-specific communication preferences: email, SMS, push
- separate transactional and marketing categories
- marketing preference synchronization with account consent flags
- verified-contact enforcement for email/SMS marketing
- mock communication adapter: events become notification history entries without external provider keys
- notification history with read/unread state
- mark one/all notifications as read
- booking-created transactional notification
- `/api/me/communications/preferences` GET/PATCH
- `/api/me/notifications` GET
- `/api/me/notifications/:id/read` POST
- `/api/me/notifications/read-all` POST
- account communication center UI

## Event model
Supported event types: BOOKING_CREATED, BOOKING_CONFIRMED, PRICE_DROP, SAVED_SEARCH_MATCH, PROMOTION_AVAILABLE, REBOOKING_REMINDER, PASSWORD_SECURITY_EVENT.
