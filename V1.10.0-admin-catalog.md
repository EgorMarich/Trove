# Trove v1.10.0 — Admin Catalog

## Что добавлено
- Управление provider-backed турами без изменения исходных данных поставщика.
- `admin_tour_overrides`: активность, featured, название, описание, badge, теги и внутренние заметки.
- Детальная страница тура в Back Office.
- Скрытие предложения из каталога через админку.
- Страница поставщиков с фактическими capabilities и health status.
- Audit event `ADMIN_TOUR_UPDATED`.
- Миграция `009_admin_tour_catalog.sql`.

## API
- `GET /api/admin/tours`
- `GET /api/admin/tours/:providerId/:offerId`
- `PATCH /api/admin/tours/:providerId/:offerId`
- `GET /api/admin/providers`

Provider data остаётся source-of-truth. Админские изменения хранятся отдельно и не перезаписывают данные интеграций.
